# ☕ Core Java

This section contains small Java programs and mini projects designed to build a strong foundation in Core Java.

## 🎯 Learning Goals

The goal is to practice:

- Variables and data types
- Operators
- Input and output
- Conditional statements
- Loops
- Methods
- Arrays
- Strings
- `switch`
- Random number generation
- Basic validation
- Logic building

## 🧪 Practice

Before building the mini projects, basic Java logic exercises will be practiced here.

Examples:

- Positive / Negative / Zero
- Even / Odd
- Largest of two or three numbers
- Leap year
- Vowel / Consonant
- Divisibility checks
- Temperature classification
- Simple mathematical problems
