# 🧪 Core Java Practice

This folder contains small programming exercises used to strengthen Java fundamentals before building complete mini-projects.

## 📚 Practice Areas

### 01 — Basic Input & Output

- Taking user input
- Displaying output
- Variables
- Data types

### 02 — Conditions

- Positive / Negative / Zero
- Even / Odd
- Largest of two numbers
- Largest of three numbers
- Leap year
- Vowel / Consonant
- Divisibility checks

### 03 — Loops

- Number patterns
- Sum of numbers
- Factorial
- Multiplication tables
- Counting digits
- Reverse a number

### 04 — Arrays & Strings

- Find maximum/minimum
- Calculate array sum
- Search an element
- Reverse an array
- Count characters
- Reverse a string

### 05 — Methods

- Calculator using methods
- Reusable validation methods
- Mathematical utility methods
- Menu-driven programs

## 🎯 Purpose

These exercises are intentionally small.

The goal is to improve:

- Logic building
- Syntax recall
- Problem decomposition
- Input handling
- Debugging
- Code-writing speed

They are practice exercises, not portfolio projects.
