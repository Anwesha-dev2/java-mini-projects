# 🎓 Student Grade Calculator

A simple console-based Java application that accepts student details and marks for five subjects and calculates the total marks, percentage, grade, and final result.

## 🎯 Objective

The purpose of this project is to practice fundamental Core Java concepts by building a small interactive application.

## ✨ Features

- Accept student name
- Accept roll number
- Accept marks for five subjects
- Calculate total marks
- Calculate percentage
- Determine grade
- Determine pass/fail result

## 🧠 Java Concepts Used

- Variables
- Data types
- `String`
- `int`
- `double`
- `char`
- `Scanner`
- Arithmetic operators
- `if-else`
- User input
- Console output
